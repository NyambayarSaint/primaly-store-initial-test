# React + TypeScript + Tailwind

A React 19 starter with TypeScript, Tailwind CSS v4, React Router v7, and Vite v7.

## Start

```bash
npm install
npm run dev
```

The browser panel will open automatically at `http://localhost:5173`.

## Structure

```
src/
  App.tsx          # Root component with router
  main.tsx         # React entry point
  index.css        # Tailwind import
  components/
    Counter.tsx    # Interactive counter demo
  pages/
    Home.tsx       # Home page
    About.tsx      # About page
```
